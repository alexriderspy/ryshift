How it works

One gesture, four seconds, zero windows.

The whole app is a single interaction. Learn it once and every conversion you do afterwards is faster than opening Preview.

Start dragging

Any file, from the desktop, Finder, Explorer, Files, or a browser download.

Press Shift

The wheel fades in under your cursor. The current wheel and the file size sit in the hub.

Hover a slice

It lights up purple and the cursor shows a green +. Tap Shift again to switch wheels.

Drop

The result is saved beside the original as Page 001.jpg. The original is never touched.

Five wheels

Each wheel holds eight slices, so nothing is more than one flick away.

Shift cycles through Convert, Tools and AI. Hold Option / Alt instead for Share and Organise. Slices you never use can be hidden, and the rest reordered.

What it does

A converter that grew up into a toolkit.

Every slice is one small Rust module: same result on every system, and adding a format is one file plus a test.

Convert anything

Images between PNG, JPG, WEBP, HEIC, TIFF, BMP, GIF and PDF. PDFs into images or text. CSV ↔ XLSX ↔ JSON. Video and audio too.

PNGJPGHEICWEBPPDFTXTMP4MP3

Compress and strip

Hit a size limit for email, WhatsApp or Discord in one drop. Drop the metadata in the same gesture, so the photo you send carries no GPS.

Crop, rotate, edit

Ratio presets for Instagram, Stories, YouTube thumbnails and LinkedIn. Adjust colours, add a gradient background, or annotate.

Redact on-device

Draw boxes, or let Auto blur the emails, phone numbers and faces it finds. Nothing leaves your machine to do it.

Batch by dragging

Drag several files at once and the action runs on all of them. Results keep the names they had, with Finder-style 2, 3 on clashes.

On-device AI

Copy text out of an image, summarise a PDF, transcribe audio to SRT. Apple Foundation Models where they exist, otherwise a small local model you opt into.

The engine is also a CLI

The Rust engine is a plain library plus a command line, so anything you can do with the wheel you can do in a script — and it's testable without any UI.

$ ryshift convert photo.heic --to jpg
✓ photo.jpg · 2.1 MB → 480 KB
$ ryshift convert report.pdf --to jpg --pages 1-3
✓ report-1.jpg  report-2.jpg  report-3.jpg

Your own slices

Pin a shell command, a Shortcut or a recipe like HEIC → JPG → resize 1080 → strip metadata and it appears as a slice for the file types you pick.

Install

About a minute, on any of the three.

Builds aren't notarised or signed yet, so each system shows one warning the first time. Here is exactly how to get past it.

macOS 12 or later

Apple Silicon: Ryshift_…_aarch64.dmg · Intel: Ryshift_…_x64.dmg

  1. Open the DMG and drag Ryshift into Applications.
  2. The first time, right-click Ryshift → Open, then Open again. A normal double-click is blocked once because builds aren't notarised yet.
  3. Ryshift appears in the menu bar. The first time you press ⌥ Space, allow it to control Finder.
Dragging files needs no permission at all — Ryshift only reads global state. Finder control is asked for once, the first time you use the shortcut.

Windows 10 & 11

Download Ryshift_…_x64-setup.exe or the .msi.

  1. Run the installer. If SmartScreen says "Windows protected your PC", click More info → Run anyway — builds aren't signed yet.
  2. Ryshift starts in the system tray.
  3. Select files in Explorer and press Ctrl + Alt + Space, or drag and hold Shift.
No admin rights needed. The wheel reads your Explorer selection through the Shell API, so there's no prompt to approve.

Ubuntu 22.04+

Download ryshift_…_amd64.deb or Ryshift_…_amd64.AppImage.

  1. Install the deb, or chmod +x the AppImage and run it.
  2. On the default Wayland session, also install the GNOME extension from the same release, then log out and back in.
  3. Turn on Ryshift in the Extensions app. The app itself must be running too.
sudo apt install ./ryshift_*_amd64.deb
scripts/pack-gnome-extension.sh gnome-extensions install --force dist/ryshift@alexriderspy.github.io.shell-extension.zip
Wayland won't let an app watch the mouse or place its own windows, so a small GNOME Shell extension spots "dragging + Shift" and moves the wheel to your pointer. The file is still dropped on Ryshift's own window, so the extension never touches files. On X11 it all works without the extension.
Questions

Reasonable things to ask before installing.

Does it upload my files?

No. Every conversion runs locally in the Rust engine on your machine. There's no account, no network call and no telemetry. The optional AI slices run on a small local model, and the only thing that ever downloads is that model (1–2 GB, opt-in) and heavy tools like ffmpeg on first use.

What happens to my original file?

It's never touched. The result is written next to it with a new extension — Page 001.pdf becomes Page 001.jpg. If a file with that name exists, you get 2, 3 and so on, exactly like Finder.

Can I use it without dragging?

Yes. Select files in Finder, Explorer or Files and press ⌥ Space on Mac or Ctrl+Alt+Space elsewhere. The wheel opens at the mouse: click a slice or press its number key, Tab switches wheels, Esc cancels.

Why does macOS and Windows warn me the first time?

Because the builds aren't code-signed yet. Notarising on macOS needs a $99/yr Apple Developer account and Windows needs a signing certificate, both of which are on the roadmap. Until then, right-click → Open on Mac and More info → Run anyway on Windows. Linux needs no signing.

Does it work on Wayland?

Yes, with the bundled GNOME Shell extension (GNOME 45+, so Ubuntu 23.10 and later). Wayland blocks apps from watching global input or placing their own windows, so the extension detects "dragging + Shift" from inside the Shell and tells Ryshift over D-Bus. On X11 no extension is needed. Other desktops like KDE or Sway get the drop-zone, right-click Open with and the CLI for now.

Is it really free? What's the catch?

MIT licensed, free forever, and the engine and CLI are open source too. There's no paid tier and nothing held back. If it saves you time, a star on GitHub or a bug report from your machine is what helps most.
